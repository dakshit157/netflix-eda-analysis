# Netflix Movies and TV Shows — EDA

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

The analysis focuses on understanding the dataset, cleaning the data, and exploring different patterns through data visualization.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Analysis Performed

* Data loading and understanding
* Dataset information and statistical analysis
* Missing value analysis and handling
* Duplicate value detection and removal
* Data type conversion
* Univariate analysis
* Bivariate analysis
* Multivariate analysis
* Data visualization
